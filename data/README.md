# Data

Do **not** commit raw recordings here (they're large and often not yours to
redistribute). Instead:

- Put a small **example** slice here for the demo, **or**
- Add a short script that **downloads** a public dataset.

Public datasets with expert-labeled ripples for validation:
- **CRCNS.org** — Buzsáki-lab hippocampal datasets (e.g. hc-3, hc-11)
- **DANDI Archive** — NWB-formatted electrophysiology
